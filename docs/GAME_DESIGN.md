# 잿빛 성벽: 최후의 수비 — 게임 설계서

> 장르: 대규모 공성 방어 전략 (가로 화면, 오프라인).
> 특정 기존 게임을 복제하지 않은 **독자 세계관·이름·그래픽(전부 코드로 그린 도형)·성 배치·유닛**입니다.

## 1. 핵심 루프

1. **출정 준비** — 정찰 보고(적 세력·유닛·조건) 확인 → 출전 분대 선택(성마다 상한) → 금화로 보급 추가.
2. **배치** — 자동 배치된 분대를 깃발 드래그로 조정 → "전투 시작".
3. **방어전** — 물결(웨이브) 단위로 몰려오는 적을 막는다. 분대는 스스로 싸우고, 플레이어는 큰 결정만 내린다.
4. **결과** — 별(본성 내구·전사 비율), 전사·부상 반영, 금화·훈장·연대기 경험치, 진급·업적.
5. **성장** — 병영(보충·치료·모집·해산), 연구(영구 강화), 다음 성.

## 2. 세계관과 세력 (모두 독자 설정)

| 세력 | 정체 | 특징 |
|---|---|---|
| 아우렐 협약군 | 인간 성전 연합 | 징집병 물량, 사다리·공성탑·투석기, 협약 대장(지휘 오라) |
| 딥홀드 씨족 | 드워프 | 중장갑 방패벽(화살 저항), 천둥석궁, 갱도병(성벽 붕괴), 철갑 충차 |
| 실반 무리 | 엘프 | 장거리 척후궁수(카이팅), 칼춤꾼, 드루이드 치유, 고목 거수 |
| 애쉬터스크 군단 | 오크 + 고블린 수행족 | 압도적 물량, 광전사, 트롤(공포), 군단장이 쓰러지면 붕괴 |
| 잿불 용족 | 고룡 + 비룡·코볼트·광신도 | 비행, 화염 숨결(원뿔 범위), 공포 오라, 체력 18% 이하면 퇴각 |
| 할드미어 변경군 | 플레이어 | 창·방패검·궁수·석궁·기사·공병·군의·노포·민병 |

## 3. 성 10곳 (단계별로 복잡해짐)

1. 개울목 초소 — 단일 성벽, 튜토리얼
2. 갈대언덕 보루 — 언덕, 측면 우회
3. 회색다리 요새 — 다리·해자, 오크
4. 늑대고개 관문 — **이중 성벽**, 드워프 갱도병·충차
5. 은빛숲 성채 — 숲, 엘프 장거리 궁수
6. 쌍둥이탑 성 — 세 방향 동시 공격(인간+오크)
7. 검은늪 수도원 — 늪·해자
8. 철모루 성 — 내성(이중 구역) 대공성전(인간+드워프)
9. 불탄왕관 성 — 고룡과 비룡
10. 최후의 성채 — 모든 세력

추가 모드: **오늘의 공성**(날짜로 결정되는 성 + 변형 규칙 6종: 정예군·보급 부족·대군·낡은 성벽·날개 달린 위협·강철 의지), **끝없는 공성**(60물결, 기록 도전).

## 4. 실제 전쟁 같은 시스템

| 시스템 | 동작 |
|---|---|
| **사기** | 분대 0–100. 75↑ 공격 +8%, 40↓ 흔들림(공격 −20%·명중 하락), 18↓ 도주(42에서 재집결). 아군 전사·주변 분대 붕괴·수적 열세·성벽 돌파·공포 유닛·식량 부족으로 하락. 본성 근처·함성·물결 격퇴·적 지휘관 처치로 회복. 계급·훈련 연구로 저항. **적 무리도 사기가 있어** 피해·지휘관 사망 시 붕괴·도주. |
| **유기적 분대 이동** | 분대마다 대형 슬롯·흐름장(다익스트라) 이동, 분리(겹침 방지), 성벽 위/아래 층 구분. **전쟁 회의 AI**가 위협(돌파·사다리·충차)을 평가해 근접 분대를 배정(히스테리시스로 흔들림 방지), 궁수는 2초마다 엄폐·사거리 좋은 성벽으로 재배치, 공병은 수리·성문 재건·진화 작업을 맡는다. **병사는 불붙은 칸과 용의 숨결에서 스스로 한 칸씩 비켜서고**(고수 범위 안, 성벽 위가 모두 타면 안뜰로. 숨결은 첫 0.6초를 맞은 뒤에야 피한다), 불이 꺼지면 제자리로 돌아온다. 땅 파는 갱도병도 위협으로 쳐서 그 위 성벽에 근접 분대를 보낸다. |
| **보급** | 화살(보급소 근처 자동 재보급, 물결 사이 30% 회수), 식량(물결마다 소모, 부족 시 사기 하락), 의약품(군의 치료), 자재(공병 수리·재건). |
| **부상** | 체력 0 → 즉사 대신 "쓰러짐"(출혈 30초+). 군의대가 치료소로 후송하면 생존 → 전투 1회 휴식 후 복귀. 방치하면 사망. 전투 후 부상병은 금화로 즉시 치료도 가능. |
| **공성** | 사다리(밀어내기 가능), 공성탑, 충차(성문), 투석기(원거리 성벽 파괴), 갱도병(12초 굴착 후 성벽 붕괴. 방패 아래라 화살 피해 ×0.6이지만 궁수의 첫 표적이고, 바로 위 성벽 병사가 떨어뜨리는 돌에 ×2.4. 한 칸에 갱도병이 여럿 붙어도 굴은 하나라 빨라지지 않고, 반쯤 판 굴은 물결 사이에 수비대가 메운다), 거수(트롤·고목), 화염(기름·숨결·화염 항아리. 항아리 불은 성벽 돌 위에서 1.2초면 꺼짐), 성벽 붕괴 → 잔해 → 공병 재건. |
| **지형·고저** | 성벽·탑 위 사거리 +25%, 엄폐(받는 원거리 피해 감소), 시야 차단(벽 너머 사격 명중 대폭 하락). |
| **지휘관 능력** | 함성(사기 +35, 도주 분대 붙잡기), 일제사격(지점 화살비), 끓는 기름(성벽 앞 화염), 증원(민병 10명, 전투당 1회). "자동 지휘관" 설정 시 AI가 사용. **작전 회의**(물결 사이 3택 1)는 고르지 않으면 다음 물결 시작 때 회의가 가장 급한 것을 스스로 택한다 — 명령을 안 하는 것이 함정이 되지 않게. |

## 5. 휴대폰 조작 설계 (가장 어려운 부분을 이렇게 풀었다)

문제: 수백 명이 싸우는 실시간 전투를 손가락 하나로 정밀 조작하는 것은 불가능에 가깝다.

해결 원칙: **미시 조작은 AI, 플레이어는 거시 결정.**

1. **기본은 전 분대 자동** — 분대 AI + 전쟁 회의가 돌파구·사다리·성문에 알아서 대응. 아무것도 안 해도 싸움은 진행된다(쉬움 난이도는 자동만으로 클리어 가능, 보통/어려움은 개입이 별을 좌우).
2. **탭 두 번 명령** — 분대 카드(하단) 또는 깃발 탭 → 땅 탭 = 이동 / 적 탭 = 집중 공격(근접 분대는 돌격). 깃발을 바로 끌어도 이동.
3. **큰 터치 영역** — 모든 버튼 40–60px, 깃발은 확대 수준과 무관하게 일정 크기, 깃발 탭 판정 반경 30px.
4. **전군 프리셋 4개** — 전원 자동 / 원위치 / 위치 고수 / 본성 후퇴 (한 번 탭).
5. **작전 일시정지** — 멈춘 상태에서도 모든 명령 가능. 배속 1·2·3×(편의 꾸러미 4×).
6. **알림 → 위치 이동** — "성문이 부서졌습니다!" 같은 알림을 탭하면 그 지점으로 화면 이동, 화면 밖 위협(사다리·용·갱도병)은 가장자리 화살표.
7. **카메라** — 한 손가락 끌기 이동, 두 손가락 확대, 두 번 탭 확대/전체 보기. 시작 시 성 중심 자동 맞춤.
8. **접근성** — 왼손 배치(능력 버튼 좌우 반전), 큰 글씨, 흔들림 줄이기, 저사양 모드, 진동 끄기.
9. **분대 카드** — 인원·사기 막대·탄약 막대·상태(수동/도주/전멸)를 한눈에.

## 6. 진행·경제

- 금화: 전투에서만 획득(전리품·첫 승리·별·오늘의 첫 승리·위로금). 사용처: 보충·치료·모집·연구·보급.
- 연구 9종(석공술·화살 장인·대장간·훈련 교범·병참·의술·노포 공학·지휘술·병영 확장).
- 분대 계급 6단계(신병→전설): 경험치는 처치·전투 참여로, 보충병은 분대 경험치를 희석.
- 훈장: 별·업적·오늘의 공성·끝없는 공성 기록으로만 획득 → 주간 진열 외관 구매.
- 전쟁 연대기: 6주 시즌 30단계, 무료/프리미엄 트랙, 시즌 보상은 시즌 번호로 자동 생성.

## 7. 기술 구조

- `src/sim` — 결정적 고정 스텝(1/30초) 시뮬레이션. DOM 의존 없음 → Node에서 헤드리스 테스트·밸런스 봇 실행.
- `src/meta` — 저장(체크섬·백업·정화·마이그레이션), 진행, 상점, 시즌, 결제 어댑터.
- `src/render` — Canvas 2D. 지형은 오프스크린에 굽고, 시체·피·그을음은 데칼 레이어에 누적, 유닛은 종류별 일괄 그리기.
- `src/ui` — 프레임워크 없는 DOM UI, 절차적 효과음(WebAudio, 음원 파일 없음).
- 외부 런타임 의존성 0개, 빌드 결과 JS 약 70KB(gzip).
