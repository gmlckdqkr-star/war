# 수익 모델 — "관리가 필요 없는" 무료 게임

## 전제 (사용자 요구)

1. 게임 자체는 무료, 꾸준한 결제를 유도하는 구조.
2. 출시 후 운영자가 관리할 것이 거의 없어야 한다: **서버 없음, 문의 최소화, 유지보수 없이 동작**.

## 설계 결정과 이유

| 결정 | 이유 (관리 부담 관점) |
|---|---|
| **비소모성 상품만 판매** (재화 판매 없음) | 비소모성은 스토어 계정에 영구 기록 → 재설치·기기 변경 시 "구매 복원"으로 자동 회복. "결제했는데 보석이 사라졌어요" 류 문의가 구조적으로 생기지 않는다. 영수증 검증 서버도 필요 없다. |
| **전투력은 팔지 않음** (외관·시즌 트랙·편의만) | 페이투윈 불만(저평점 1순위)과 밸런스 패치 압박 제거. 금화·병력·연구는 전투로만 획득. |
| **시즌 패스 = 시즌마다 별도 상품 ID** (`chronicle_s01` … `chronicle_s24`) | 출시 전에 24개(약 2년 9개월치)를 한 번에 등록해 두면 끝. 시즌은 **기기 날짜로 자동 회전**(6주), 보상 외관은 시즌 번호로 **자동 생성** → 콘텐츠 업로드·서버 이벤트 불필요. 25번째 시즌부터는 프리미엄 트랙이 자동으로 숨겨지고 무료 트랙만 계속 돈다. |
| **훈장(무료 재화)은 플레이로만** + 주간 진열 | 매주 돌아오는 이유 제공. 진열은 날짜 기반 결정적 회전이라 서버 불필요. |
| **광고 없음, 분석 SDK 없음, 계정 없음** | 개인정보 수집 0 → 개인정보처리방침이 단순, 데이터 유출·삭제 요청 대응 없음. 광고 SDK 업데이트·정책 위반 경고 관리 없음. |
| **확률형 아이템 없음** | 확률 공개 의무·규제 리스크 없음. |
| **오프라인 저장 + 자동 백업 + 저장 코드** | 손상 시 백업에서 자동 복구, 기기 이전은 저장 코드(결제 정보는 코드에 포함되지 않음 → 코드 공유로 유료 아이템 복제 불가). |

## 상품 목록

| ID | 이름 | 가격(KRW 기준) | 내용 |
|---|---|---|---|
| `chronicle_sNN` (01–24) | 프리미엄 연대기 | ₩5,500 | 해당 시즌 프리미엄 트랙(시즌 한정 깃발 2·갑주·성채·칭호 + 훈장·금화). 이미 오른 단계 보상 즉시 수령 |
| `supporter_small` | 변경 후원 (소) | ₩2,200 | 후원자 깃발 + "후원자" 칭호 |
| `supporter_large` | 변경 후원 (대) | ₩6,600 | 소 + 황금 근위 갑주 + 백대리석 성채 |

※ 가격은 스토어 콘솔에서 국가별로 설정하며, 앱은 스토어가 알려준 현지 가격을 표시한다.

## 꾸준한 결제가 생기는 구조

- 6주마다 새 시즌 + 새 한정 외관 → 시즌 패스 재구매 동기(가장 큰 반복 매출원).
- 연대기 경험치는 모든 전투에서 쌓임 → 무료 트랙으로 맛보고, 프리미엄 잠금 보상이 눈에 보임(강요 없음, 이미 쌓은 단계도 소급 지급되어 "늦게 사도 손해 없음").
- 성 외관·깃발·갑주 색은 전장에 직접 보임 → 과시·수집 욕구.
- 편의 꾸러미는 반복 플레이가 쌓인 사용자를 위한 1회성 상품.

## 운영자가 할 일 (출시 후)

- 없음이 목표. 예외: 2년 9개월 뒤 시즌 상품을 더 쓰려면 `MAX_REGISTERED_SEASONS`를 올리고 상품 ID를 추가 등록하는 앱 업데이트 1회.
- 문의가 와도 답할 수 있는 표준 답변 3개: "구매 복원 버튼", "설정 → 저장 코드", "설정 → 오류 기록 복사".
