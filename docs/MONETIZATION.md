# 수익 모델 — "관리가 필요 없는" 무료 게임

## 전제 (사용자 요구)

1. 게임 자체는 무료, 꾸준한 결제를 유도하는 구조.
2. 출시 후 운영자가 관리할 것이 거의 없어야 한다: **서버 없음, 문의 최소화, 유지보수 없이 동작**.

## 설계 결정과 이유

| 결정 | 이유 (관리 부담 관점) |
|---|---|
| **비소모성 상품만 판매** (재화 판매 없음) | 비소모성은 스토어 계정에 영구 기록 → 재설치·기기 변경 시 "구매 복원"으로 자동 회복. "결제했는데 보석이 사라졌어요" 류 문의가 구조적으로 생기지 않는다. 영수증 검증 서버도 필요 없다. |
| **전투력은 팔지 않음** (외관·시즌 트랙·편의만) | 페이투윈 불만(저평점 1순위)과 밸런스 패치 압박 제거. 금화·병력·연구는 전투로만 획득. |
| **시즌 패스 = 시즌마다 별도 상품 ID** (`chronicle_s01` … `chronicle_s24`) | 출시 전에 24개(약 2년 9개월치)를 한 번에 등록해 두면 끝. 시즌은 **기기 날짜로 자동 회전**(6주), 보상 외관은 시즌 번호로 **자동 생성**(시즌 9부터는 색 조합도 자동 생성되어 같은 외관을 다시 팔지 않음) → 콘텐츠 업로드·서버 이벤트 불필요. 25번째 시즌부터는 프리미엄 트랙이 자동으로 숨겨지고 무료 트랙만 계속 돈다. |
| **시즌 패스 구매 = 시즌 외관 5종 즉시·영구 지급** | 산 것이 바로 보이고(전환율), 시즌이 끝나도 사라지지 않으며, 지난 시즌 패스도 스토어 "구매 복원"으로 외관을 되찾는다 → 애플 비소모성 요건(영구 콘텐츠)과 "샀는데 사라졌다" 문의를 동시에 해결. 프리미엄 트랙은 훈장만 추가로 준다. |
| **시즌 종료 시 자동 수령 + 시즌별 진행 보관** | 받지 않은 보상이 사라지는 불만 제거. 기기 시계를 앞뒤로 바꿔도 진행이 지워지지 않음. |
| **훈장(무료 재화)은 플레이로만** + 주간 진열 | 매주 돌아오는 이유 제공. 진열 = 기본 품목 3 + 그 주에만 나오는 자동 생성 공방 품목 2 + 지난 시즌 무료 외관 1 → 훈장 쓸 곳이 계속 생김. 날짜 기반 결정적 회전이라 서버 불필요. |
| **결제로 금화를 주지 않음** | 프리미엄 트랙·빠른 소탕 모두 금화 없음. "금화는 전투로만"이라는 문구가 사실이어야 허위 광고·페이투윈 리뷰가 안 생김. |
| **광고 없음, 분석 SDK 없음, 계정 없음** | 개인정보 수집 0 → 개인정보처리방침이 단순, 데이터 유출·삭제 요청 대응 없음. 광고 SDK 업데이트·정책 위반 경고 관리 없음. |
| **확률형 아이템 없음** | 확률 공개 의무·규제 리스크 없음. |
| **오프라인 저장 + 자동 백업 + 저장 코드** | 손상 시 백업에서 자동 복구, 기기 이전은 저장 코드(결제 정보는 코드에 포함되지 않음 → 코드 공유로 유료 아이템 복제 불가). |

## 꾸준한 결제가 생기는 구조

- 6주마다 새 시즌 + 새 한정 외관 → 시즌 패스 재구매 동기(가장 큰 반복 매출원).
- 연대기 화면에 이번 시즌 외관 5종이 **그림으로** 보이고, 다음 시즌 외관도 미리 보여 준다(날짜로 정해지므로 서버 불필요) → "다음 시즌도 사야지" 동기.
- 연대기 경험치는 모든 전투에서 쌓임 → 무료 트랙으로 맛보고, 프리미엄 훈장 보너스는 이미 오른 단계도 소급 지급("늦게 사도 손해 없음"). 시즌 마지막 7일에는 구매 전에 남은 기간을 알려 준다.
- 성 외관·깃발·갑주 색은 전장에 직접 보임 → 과시·수집 욕구. 상점·옷장도 모두 그림 미리보기.
- 편의 꾸러미는 반복 플레이가 쌓인 사용자를 위한 1회성 상품.

## 운영자가 할 일 (출시 후)

- 없음이 목표. 예외: 2년 9개월 뒤 시즌 상품을 더 쓰려면 `MAX_REGISTERED_SEASONS`를 올리고 상품 ID를 추가 등록하는 앱 업데이트 1회.
- 문의가 와도 답할 수 있는 표준 답변 3개: "구매 복원 버튼", "설정 → 저장 코드", "설정 → 오류 기록 복사".
